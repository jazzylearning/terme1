Potenzgesetze auf einen Blick

Achte bei jedem Gesetz auf seine Voraussetzungen – besonders bei Division, Null- und negativen Exponenten.

Produkt gleicher Basis

aᵐ · aⁿ = aᵐ⁺ⁿ

Die Basis bleibt, die Exponenten werden addiert. Für ganzzahlige Exponenten; bei negativen Exponenten muss a ≠ 0 gelten.

Quotient gleicher Basis

aᵐ / aⁿ = aᵐ⁻ⁿ

Die Basis bleibt, die Exponenten werden subtrahiert. Voraussetzung: a ≠ 0.

Potenz einer Potenz

(aᵐ)ⁿ = aᵐⁿ

Die Exponenten werden multipliziert. Bei negativen Exponenten darf keine Nullbasis entstehen.

Produkt potenzieren

(a · b)ⁿ = aⁿ · bⁿ

Der Exponent wirkt auf jeden Faktor. Gilt für ganzzahlige n; bei n < 0 müssen a und b ungleich 0 sein.

Quotient potenzieren

(a / b)ⁿ = aⁿ / bⁿ

Der Exponent wirkt auf Zähler und Nenner. Voraussetzung: b ≠ 0; bei n < 0 zusätzlich a ≠ 0.

Nullpotenz

a⁰ = 1

Voraussetzung: a ≠ 0. Der Ausdruck 0⁰ wird hier nicht definiert.

Negativer Exponent

a⁻ⁿ = 1 / aⁿ

Ein negativer Exponent bedeutet Kehrwert. Voraussetzung: a ≠ 0.

Gebrochene Exponenten

aᵖ⁄ᑫ = ᑫ√(aᵖ)

Im reellen Bereich ist a > 0 eine sichere Voraussetzung für beliebige reelle Exponenten. Bei geradem q und a < 0 ist die Wurzel nicht reell; Randfälle hängen von p und q ab.
